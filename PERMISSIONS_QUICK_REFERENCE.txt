  # Check if user can create projects
  if has_permission(user, 'projects', 'create'):
      # CEO only
  
  # Check if user can assign tasks to anyone
  if has_permission(user, 'tasks', 'assign_anyone'):
      # CEO only
  
  # Check if user can mark attendance
  if has_permission(user, 'attendance', 'create'):
      # HR only

  {% endif %}

KEY DIFFERENCES
================================================================================

CEO:      Full access to everything, can override any restriction
HR:       Full access to attendance/leaves/payroll, NO project internals
PM:       Only assigned projects, can assign Dev/UIUX to assigned projects
DEV:      Read-only projects, can update assigned tasks, submit daily updates
UIUX:     Same as DEV + can upload assets and add Figma links
BDE:      Full access to leads, read-only project overview
